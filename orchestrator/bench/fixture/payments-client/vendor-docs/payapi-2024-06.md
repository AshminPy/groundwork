# PayAPI reference — API version 2024-06

## Listing invoices
- Maximum `limit` (page size): 100.
- Offset pagination returns at most 10,000 results in total; requests with `offset` above 10,000 fail with 400.
- For larger result sets use cursor pagination: `GET /v1/invoices?cursor=&limit=`, following `next_cursor`.

## Idempotency
- Send the `X-PayAPI-Idempotency` header on POST requests.
- The old `Idempotency-Key` header is ignored in this version: such requests are not idempotent.
- Retrying a POST /v1/refunds request without a valid `X-PayAPI-Idempotency` header can create duplicate refunds.
