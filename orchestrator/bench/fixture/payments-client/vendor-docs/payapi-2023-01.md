# PayAPI reference — API version 2023-01

## Listing invoices
`GET /v1/invoices?offset=&limit=` — offset pagination. Maximum `limit` (page size): 50.

## Idempotency
Send the `Idempotency-Key` header on POST requests. A repeated request with the same key returns the original result.

## Refunds
A refund can be created up to 180 days after the original charge.
